# MicroCalc для WordPress 6.3+

1. Плагины → Добавить новый → Загрузить `microcalc-widget-<версия>.zip` из [Releases](https://github.com/calculatoriru/pub_plugins/releases) и активировать.
2. Настройки → MicroCalc: принять условия, выбрать оформление по умолчанию.
3. В редакторе добавить блок «MicroCalc» и выбрать калькулятор по названию. Или шорткод `[microcalc id="318"]`, или виджет «Калькулятор MicroCalc» в боковой колонке.
4. Опубликовать страницу и проверить её кнопкой «Проверить установку» в настройках.

Адрес сервиса меняется в настройках или константой `MICROCALC_WIDGET_BASE` в `wp-config.php`. Описание для каталога WordPress — `readme.txt`.
