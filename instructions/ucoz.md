# uCoz / uKit

**uCoz.** Панель управления → «Редактор страниц» (или модуль, где нужен калькулятор) → переключите редактор в режим HTML (кнопка «HTML» или «Исходный код») → вставьте код целиком → сохраните. Для всех страниц сразу код можно поставить в шаблон: «Дизайн» → «Управление дизайном (шаблоны)».

**uKit.** Виджет «HTML-код» кладёт код в отдельный фрейм, как Wix: см. [frames.md](frames.md).

Проверьте страницу на странице настройки виджета.
