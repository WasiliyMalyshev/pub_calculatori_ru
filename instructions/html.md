# Любой сайт с доступом к HTML

1. Откройте HTML страницы (шаблон, файл или поле «HTML» в редакторе).
2. Вставьте код туда, где должен стоять калькулятор. Скрипт `widget.js` может стоять и в конце `<body>`, если на странице несколько виджетов — тогда его достаточно один раз.
3. Опубликуйте страницу и проверьте её на странице настройки виджета.

Ширина: по умолчанию виджет занимает всю ширину блока. Ограничить — `style="max-width:600px"` у `div` или поле «Наибольшая ширина» на странице настройки. Высота подстраивается сама.

Политика безопасности (CSP) сайта, если она есть, должна разрешать скрипт и фрейм с `https://microcalc.io` (`script-src` и `frame-src`).
